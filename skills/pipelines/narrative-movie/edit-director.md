# Picture Editor — Narrative Movie Pipeline

Create normal OpenMontage `edit_decisions` from the actual QA-approved takes.

The pre-edit shot plan is evidence, not a locked assembly recipe. Judge the available material by emotion, story, attention, rhythm, continuity, and technical cleanliness. Choose performance and reactions, trim to usable frames, shape pauses and reveals, and use J/L cuts or sound bridges when they improve the scene.

Use only accepted take ranges. If the best dramatic cut requires a continuity risk, record the reason. If the necessary edit cannot be built, send the precise missing coverage or regeneration need back to the relevant earlier stage.
